# Semana 2

Repositorio con los ejercicios y la tarea de la **Semana 2**, enfocados en **asincronismo en JavaScript** y una práctica básica de **HTML y CSS**.

## Asincronismo

Dentro de la carpeta `asincronismo/` se encuentran tres ejemplos que muestran las distintas formas de manejar operaciones asíncronas en JavaScript:

| Archivo | Descripción |
|---------|-------------|
| `callbacks.js` | Manejo de asincronismo mediante funciones *callback*. |
| `promesas.js` | Uso de promesas. |
| `async_await.js` | Sintaxis moderna con `async` / `await`.|

Además, se incluye el documento **`TAREA SEM#2 - DANIEL DUEÑAS.pdf`** con la tarea de la semana.

---

## HTML

La carpeta `html/` contiene una página web sencilla con:

- `index.html`: página principal.
- `styles/styles.css`: hoja de estilos.
- `images/`: recursos gráficos (`favicon.ico` y `google_logo.webp`).
